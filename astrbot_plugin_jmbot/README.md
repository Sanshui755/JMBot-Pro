# JMBot (AstrBot 版)

禁漫天堂漫画下载插件。群聊 / 私聊发送 `/jm <id>`，机器人自动下载相册、生成 PDF 并发送文件。

支持批量：`/jm 350234 350235`、一条消息多条 `/jm` 指令、`/jm350234`（无空格）、`/jm 350234极品`（只取数字前缀）。

下载产物（图片/PDF/加密PDF）仅在本机保留 3 天，到期自动删除。

移植自 ncatbot5 版 JMBot。

## 功能

- `/jm <id>` — 下载指定本子并发送 PDF（群聊需先由超管开启，可批量）
- `/jm help` — 查看用法
- 群管理命令（仅超管）：`开启JMBot` / `关闭JMBot` / `测试JMBot`
- 私聊管理命令（仅超管）：
  - `打开加密` / `关闭加密` — 开关 PDF 加密
  - `PDF密码` — 查看当前 PDF 密码
  - `设置PDF密码 <密码>` — 设置 PDF 加密密码
  - `下载路径` / `设置下载路径 <路径>` — 查看/修改下载目录（自动迁移旧文件）
  - `设置JM账号 <用户名>` / `设置JM密码 <密码>` — 保存 JM 账号并登录
  - `JM登录` — 手动重新登录
  - `JM状态` — 查看账号与登录状态
  - `清除JM账号` — 删除已保存的账号密码
  - `JM帮助` — 查看管理命令
- **登录测试**：在 WebUI 插件配置页填写 JM 账号/密码并保存后，插件自动热重载并立即测试登录，成功/失败结果在 WebUI「日志」页查看（搜「JM 登录」），也可私聊发送 `JM状态` 确认

## 安装

1. 将本插件目录放入 AstrBot 的 `data/plugins/` 下（或打包成 zip 在 WebUI 安装，zip 根目录需为 `astrbot_plugin_jmbot/` 单一文件夹）
2. 启动 AstrBot，依赖会自动安装（或手动 `pip install -r requirements.txt`）
3. 在 AstrBot WebUI「插件管理 → JMBot → 配置」中填写**超管QQ号**（不知道自己的 ID 可在聊天中发送 `/sid` 获取），并按需设置群聊开关与 PDF 加密
4. 私聊机器人发送 `设置JM账号 <用户名>`、`设置JM密码 <密码>` 登录 JM

## 配置（WebUI 可视化）

| 配置项           | 说明                                           | 默认值                          |
| ---------------- | ---------------------------------------------- | ------------------------------- |
| 超管QQ号         | 管理命令仅此人可用（私聊发送管理命令）         | 空                              |
| 群聊下载开关     | 关闭时群聊 `/jm` 静默忽略                      | 关                              |
| 群聊PDF加密开关  | 群聊发送的 PDF 是否加密（私聊始终不加密）      | 开                              |
| PDF加密密码      | 群聊加密 PDF 的密码                            | 114514                          |
| 下载文件保存路径 | 下载根目录，其下自动维护 stock/pdf/encrypt_pdf | 空 = `用户目录\JMBot-Downloads` |

> JM 账号密码在此配置页填写并**保存**后，插件会自动热重载并立即尝试登录（相当于自动做一次登录测试）；结果在 WebUI「日志」页查看，无需再手动重载。

下载文件保存在「下载文件保存路径」配置的目录下（留空时默认为 `用户目录\JMBot-Downloads`，Windows 即 `C:\Users\你\JMBot-Downloads`）：

- `stock\` — 下载的图片缓存
- `pdf\` — 生成的 PDF（即默认在 `用户目录\JMBot-Downloads\pdf`）
- `encrypt_pdf\` — 加密后的 PDF

以上下载产物超过 3 天后会在清理周期（每 6 小时一次）自动删除；用「设置下载路径」改目录时旧文件会自动迁移。

账号等运行时数据保存在 `data/plugin_data/astrbot_plugin_jmbot/`：

- `jm_account.json` — JM 账号密码（明文，仅本机）
- `config.yml` — jmcomic 下载配置（自动生成，路径已绝对化）
