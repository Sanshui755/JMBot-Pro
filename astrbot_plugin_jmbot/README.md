# JMBot (AstrBot 版)

> [!CAUTION]
> **请勿大批量、高频率下载漫画**——本插件仅面向个人自用、按需下载。大量并发请求会加重禁漫站点服务器负担，也可能触发风控导致账号或 IP 被限制。请自觉控制下载数量与频率，滥用后果自负。

禁漫天堂漫画下载插件。群聊 / 私聊发送 `/jm <id>`，机器人自动下载相册、生成 PDF 并发送文件。

支持批量：`/jm 350234 350235`、一条消息多条 `/jm` 指令、`/jm350234`（无空格）、`/jm 350234极品`（只取数字前缀）。

只看详情不下载：`/jmv 350234`，也可直接粘贴含车号的链接或整段文本（如 `/jmv https://18comic.vip/album/350234/`），机器人会自动提取其中的车号。

下载产物（图片/PDF/加密PDF）在本机短期保留，到期自动删除（保留天数可在插件配置页设置，默认 3 天，也可整体关闭自动清理）。

移植自 ncatbot5 版 JMBot。

## 功能

- `/jm <id>` — 下载指定本子并发送 PDF（群聊需先由超管开启，可批量）
- `/jm -h <id>` — 超分辨率下载，使用 WebUI 配置页选定的默认模型（可在配置中切换 Real-ESRGAN / waifu2x）；图片需逐张放大，**耗时比普通下载明显增加，请耐心等待**
- `/jm -hr <id>` — 强制用 Real-ESRGAN 超分（anime 模型 4x 放大，首次自动下载约 45MB 工具包，无需 torch）
- `/jm -hw <id>` — 强制用 waifu2x 超分（cunet 动漫模型，降噪级别 2，2x 放大，首次自动下载约 35MB 工具包）
- `/jm help` — 查看用法
- `/jms <关键词>` — 站内搜索本子（每页 10 条：车号/标题/标签），兼容 `/jms关键词` 无空格写法；回复 `1` 看下一页、`0` 退出，5 分钟内仅搜索发起人本人操作有效
- `/jma <作者名>` — 按作者搜索本子（每页 10 条），兼容 `/jma作者名` 无空格写法，翻页方式同 `/jms`
- `/jmv <任意含车号的文本>` — 查询本子详情（不下载），自动提取文本中的车号，可直接粘贴链接或整段内容；兼容 `/jmv350234` 无空格写法；支持批量：`/jmv 350234 350235`（也可粘贴含多条链接的文本，逐条发送结果，单条失败不影响其余）；详情以「车号+标题 → 封面大图 → 其余信息」单条图文消息发送（封面缓存于下载目录 `cover_cache`，随自动清理一起删除（保留天数同配置页）；封面获取失败自动降级纯文本）
- 群管理命令（仅超管）：`开启JMBot` / `关闭JMBot` / `测试JMBot`
- 私聊管理命令（仅超管）：
  - `打开加密` / `关闭加密` — 开关 PDF 加密
  - `PDF密码` — 查看当前 PDF 密码
  - `设置PDF密码 <密码>` — 设置 PDF 加密密码
  - `下载路径` / `设置下载路径 <路径>` — 查看/修改下载目录（自动迁移旧文件）
  - `设置JM账号 <用户名>` / `设置JM密码 <密码>` — 保存 JM 账号并登录
  - `JM登录` — 手动重新登录
  - `JM状态` — 查看账号与登录状态
  - `清除JM账号` — 删除已保存的账号密码
  - `JM帮助` — 查看管理命令
- **登录测试**：在 WebUI 插件配置页填写 JM 账号/密码并保存后，插件自动热重载并立即测试登录，成功/失败结果在 WebUI「日志」页查看（搜「JM 登录」），也可私聊发送 `JM状态` 确认
- **每日自动签到**：配置页开关默认开启；每天第一次使用任意 JM 指令（`/jm`、`/jmv`、`/jms`、`/jma`）时后台自动完成禁漫账号签到（领取金币/经验），走移动端 API，不发送 QQ 消息；最近一次签到的时间与结果自动回填在开关下方的「签到信息」框（重新打开配置页即可查看，无需翻日志），失败原因同样显示并在当天后续调用时自动重试
- **WebUI 实时进度页**：在 AstrBot WebUI「插件管理 → JMBot → 进度页」打开，实时显示每个任务的排队/准备/下载/超分/PDF 各阶段：多章专辑分段进度条、剩余时间估算、失败原因与回退提示；页面每 1 秒自动刷新，PDF 发送成功后移出主列表并自动归档到页面底部「历史记录」（保留最近 100 条）

## 安装

1. 将本插件目录放入 AstrBot 的 `data/plugins/` 下（或打包成 zip 在 WebUI 安装，zip 根目录需为 `astrbot_plugin_jmbot/` 单一文件夹）
2. 启动 AstrBot，依赖会自动安装（或手动 `pip install -r requirements.txt`）
3. 在 AstrBot WebUI「插件管理 → JMBot → 配置」中填写**超管QQ号**（不知道自己的 ID 可在聊天中发送 `/sid` 获取），并按需设置群聊开关与 PDF 加密
4. 私聊机器人发送 `设置JM账号 <用户名>`、`设置JM密码 <密码>` 登录 JM

## 配置（WebUI 可视化）

| 配置项             | 说明                                             | 默认值                          |
| ------------------ | ------------------------------------------------ | ------------------------------- |
| 超管QQ号           | 管理命令仅此人可用（私聊发送管理命令）           | 空                              |
| 群聊下载开关       | 关闭时群聊 `/jm` 静默忽略                        | 关                              |
| 群聊PDF加密开关    | 群聊发送的 PDF 是否加密（私聊始终不加密）        | 开                              |
| PDF加密密码        | 群聊加密 PDF 的密码                              | 114514                          |
| 超分辨率功能总开关 | 关闭后 `/jm -h/-hr/-hw` 自动回退普通下载         | 开                              |
| 超分辨率默认模型   | `/jm -h` 使用的模型（Real-ESRGAN / waifu2x）     | Real-ESRGAN                     |
| JM 账号 / JM 密码  | 禁漫登录凭据，保存后自动测试登录                 | 空                              |
| 每日自动签到       | 每天首次使用任意 JM 指令时后台签到，不发消息     | 开                              |
| 签到信息           | 自动回填，显示最近一次签到时间与结果（只读展示） | 今日尚未执行签到                |
| 下载产物自动清理   | 关闭后原图/PDF/封面缓存长期保留、不自动删除      | 开                              |
| 文件保留天数       | 自动清理的保留天数，可填 1-365（整数）           | 3 天                            |
| 批量下载数量上限   | 单次 `/jm` 最多下载的本子数，0 = 无上限          | 0（无上限）                     |
| 批量查询数量上限   | 单次 `/jmv` 最多查询的本子数，0 = 无上限         | 0（无上限）                     |
| 下载文件保存路径   | 下载根目录，其下自动维护 stock/pdf/encrypt_pdf   | 空 = `用户目录\JMBot-Downloads` |

> JM 账号密码在此配置页填写并**保存**后，插件会自动热重载并立即尝试登录（相当于自动做一次登录测试）；结果在 WebUI「日志」页查看，无需再手动重载。

下载文件保存在「下载文件保存路径」配置的目录下（留空时默认为 `用户目录\JMBot-Downloads`，Windows 即 `C:\Users\你\JMBot-Downloads`）：

- `stock\` — 下载的图片缓存；超分图片按模型分文件夹存放：`stock\_hr_realesrgan\<本子>\<章节>\` 与 `stock\_hr_waifu2x\<本子>\<章节>\`
- `pdf\` — 生成的 PDF（即默认在 `用户目录\JMBot-Downloads\pdf`）
- `encrypt_pdf\` — 加密后的 PDF

以上下载产物超过配置的保留天数（默认 3 天）后会在清理周期（每 6 小时一次）自动删除，自动清理可在配置页整体关闭；用「设置下载路径」改目录时旧文件会自动迁移。

账号等运行时数据保存在 `data/plugin_data/astrbot_plugin_jmbot/`：

- `jm_account.json` — JM 账号密码（明文，仅本机）
- `config.yml` — jmcomic 下载配置（自动生成，路径已绝对化）
- `realesrgan/` — Real-ESRGAN 超分工具（首次使用 `/jm -h`/`-hr` 时自动下载）
- `waifu2x/` — waifu2x 超分工具（首次使用 `/jm -hw` 时自动下载）
